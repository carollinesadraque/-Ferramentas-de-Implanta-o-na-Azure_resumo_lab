# -Ferramentas-de-Implanta-o-na-Azure_resumo_lab
 Ferramentas de Implantação na Azure_resumo_lab
no Portal da Azure: (https://portal.azure.com), que é uma ferramenta que serve para configurar e monitorar recursos como criar uma maquina virtural por exemplo, podendo criar através da opção + Criar Recurso. Para acessar a plataforma basta criar uma conta junto a microsoft, navegar no meu lateral e sleecionar recurrsos. 
O Azure Powershell é uma das ferramentas de implantação de recursos do Azure: é um conjunto de módulos que permitem gerenciar recursos via powershell (linguagem da microsoft). Funciona como uma ponte entre o computador e o Azure. Servie para automatizar tarefas, criar, atualizar e excluir recursos sem precisar usar o portal. Tendo sua funcinalidade voltada para automação e gerenciamento de recursos com scripts. Um exemplo de configuração: instalar módulo Az: autenticar com connect AZaccount, tipo: CLI baseada em powershell, pode ser usada por administradores windows e automação avançada. SErvie para criar maquinas virtuais, redes, banco de dados, gerenciar grupos de recursos, alicar po´liticas, tags e permissões, atuomatizar tarefas repetitivas para economizar tempo. A instalação: no windows ja vem instalado, no linux ou mac, precisa baixar atraves do link: https://aka.ms/powershell. As vantagens do Azure Powershell são: rapido para criar recursos em massa, muito util pra engenheiros de nuvem e administradores, pode ser usado localmente ou em scripts no azuredevops.
o Azure Cloud Shell: e um ambiente de linha de comando hospedado no navegador. Ja vem configurado com Azure CLI e PowerShell. Serive para executar comandos e scripts do Azure sem instalar nada no computador, gerenciar recursos de qualquer lugar com apenas um navegador. Exemplo: ciar um grupo de recursos via cloud shell: AZ group create - noame meugrupocloudshell-location eastus. Ao abrir o cloud shell, escolher entre Bash (linux) ou powershell (windows).
A interface de linha de comando (azure CLI): É uma ferramenta para gerenciar recursos do Azure via terminal, serve para criar,atualizar e monitorar recursos do azure usando scripts ou comandos. Funciona no windows, linux e mac. Um exemplo, criando uma VM: AZ vm create - resource-group meu grupo - name minha VM - image ubuntuLTS - size standard-B1s. CLI é mais multiplataforma, power shell é mais integrado ao windows.
Os Grupos de Recursos (Resource Groups): são conteiners logicos para organizar recursos relacionados no azure. Servem para facilitar gerenciamento, permissões, monitoramento e cobrança de recursos. Exemplo: colocarVM, banco de dados e rede no mesmo grupo. Recuros podem ser movidos entre grupos, mas so podem pertencer a um grupo de cada vez. Exemplo de grupo de recursos: az group create - name meu grupo - location eastus
A VNET1 e uma rede virtual do Azure: rede privada que conecta recursos entre si, como uma LAN em nuvem. Permite comunicação segura entre VMS, banco de dados e serviços. Isola recursos da internet publica. Um exemplo: criando uma vnet com subrede: az network vnet create - resource group meu grupo - name vnet1-address-prefix 11.0.0.1/15-subnet name subrede1...Obs: voce pode conectar VNets entre regiões ou com sua rede local usando VPN ou ExpressRoute.
O Azure ARC é uma plataforma que permite gerenciar recursos fora do Azure (on-premises ou outras nuvens) como se estivessem no Azure. Servem para aplicar governança, politicas e monitoramento centralizado em servidores, clusters kubernetes e banco de dados externos. Exemplo: registrar um servidor local no azure arc para aplicar azure policy de segurança. Ideal para empresas com infraestrutura hibrida ou multicloud.
My Dashborard (meu painel) é um painel personalizavel dentro do portal da azure, serve para visualizar recursos, alertas e custos em uma unica tela.Para conifgurar clique em paineis + novo painel, arraste blocos de metricas, graficos ou recursos e salve ou compartilhe. Exemolo: pode criar um painel mostrando alertas de segurança, consumo de armazenamento, uso de CPU da VM etc.
